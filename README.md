### Análisis Predictivo del Potencial Eólico

Caso de estudio y examen académico desarrollado en colaboración con un compañero para la asignatura de Minería de Datos.

El proyecto tuvo como objetivo analizar información meteorológica y ambiental de distintas ubicaciones de Australia para estimar su potencial eólico y apoyar la preselección de zonas aptas para la instalación de parques eólicos.

El trabajo siguió una metodología estructurada basada en **CRISP-DM**, abarcando la comprensión del problema, exploración y preparación de los datos, aplicación de técnicas de minería de datos, evaluación de resultados y elaboración de recomendaciones.

La participación fue colaborativa y equitativa, distribuyendo entre ambos integrantes las tareas de preparación de datos, análisis exploratorio, modelado, interpretación de resultados, documentación y presentación del caso de estudio.

**Nuestra participación:**

- Comprensión del problema y definición del objetivo de análisis.
- Revisión, limpieza y transformación del conjunto de datos.
- Tratamiento de valores faltantes y datos atípicos.
- Conversión de variables categóricas para su uso en modelos.
- Creación de nuevas características a partir de los datos meteorológicos.
- Desarrollo del análisis exploratorio de datos.
- Aplicación y evaluación de técnicas de minería de datos.
- Interpretación de patrones y resultados.
- Elaboración conjunta del informe y las conclusiones.
- Definición de recomendaciones y posibles mejoras futuras.

**Técnicas aplicadas:**

- Análisis exploratorio y visualización de datos.
- Ingeniería de características meteorológicas.
- Clustering mediante **K-Means**.
- Evaluación del número de grupos mediante el método del codo y **Silhouette Score**.
- Análisis conceptual de reglas de asociación mediante **Apriori**.
- Regresión lineal para estimar el potencial de generación.
- Exploración de modelos de clasificación para determinar niveles de viabilidad o riesgo.
- Evaluación mediante métricas aplicables a regresión y clasificación.

**Resultados principales:**

- Identificación de cuatro perfiles de condiciones meteorológicas con comportamientos diferenciados.
- Segmentación de escenarios de alto y bajo potencial eólico.
- Análisis de la relación entre velocidad del viento y potencia estimada.
- Identificación de variables meteorológicas relevantes para la evaluación de ubicaciones.
- Generación de gráficos y visualizaciones para comunicar los hallazgos.
- Elaboración de recomendaciones para mejorar la selección preliminar de emplazamientos.
- Propuesta de evolución hacia pipelines automatizados, reentrenamiento de modelos y dashboards interactivos.

**Repositorio:** [Parques_Eolicos](https://github.com/NicAHS/Parques_Eolicos)

> Proyecto académico desarrollado de manera colaborativa con fines educativos y de demostración de competencias en análisis de datos.

## Cómo trabajo

Mi forma de desarrollar se basa en:

1. Comprender primero el problema y las reglas de negocio.
2. Dividir el trabajo en entregas pequeñas y verificables.
3. Priorizar soluciones mantenibles sobre implementaciones innecesariamente complejas.
4. Validar cada cambio antes de avanzar.
5. Documentar decisiones, configuraciones y procedimientos.
6. Considerar desde el inicio la seguridad y la experiencia del usuario.
7. Analizar los errores desde la causa raíz, no solo corregir el síntoma.
